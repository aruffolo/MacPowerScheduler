# Changelog

## 0.1.0

- Add a native macOS daily wake/power-on and shutdown editor with the Quiet Agenda interface and Settings.
- Include a CLI with JSON output, conflict detection and revocable account-level automation access.
- Preserve existing one-time events and require acknowledgement before replacing unsupported repeating schedules.
- Preserve unsaved editor changes across temporary schedule-read failures.
- Provide Universal and Apple Silicon-only release packaging, matching debug symbols and SHA-256 checksums.
