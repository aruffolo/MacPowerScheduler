# commits.md

## Commit & PR Guidelines
- Conventional Commits: `feat|fix|refactor|build|ci|chore|docs|style|perf|test`.
- Prefer the `committer` helper on PATH when available; stage only task-owned files. This repository has no `scripts/committer`.
- Mention verification in PR text (e.g., `make check`, `make test-strict`, `make build-universal`).
- Commit and push only with the authorization required by `AGENTS.md`.
