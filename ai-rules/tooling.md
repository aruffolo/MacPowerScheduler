# Tooling: Peekaboo + Axe

Use these tools to *see* the UI, inspect accessibility trees, and validate accessibility.

## Peekaboo (screenshots + UI inspection)
Use when:
- You need screenshots to understand UI state.
- You need to inspect visible UI elements / click targets.

Safety:
- Ask before interacting with destructive UI controls (delete/reset/purchases).
- Prefer read-only inspection commands unless explicitly asked to click/type.

## Axe (accessibility audit)
Use when:
- Auditing web content (marketing site, webviews, HTML exports) for common a11y violations.

Notes:
- For native macOS UI, prioritize platform accessibility tools and Peekaboo inspection.
