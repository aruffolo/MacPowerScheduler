# MacPowerScheduler 0.1.0

MacPowerScheduler provides a native daily startup/shutdown editor and a bundled CLI for macOS 14 or later.

This first release is a pre-release with the validation limits below. Both downloads are Developer ID signed and notarized by Apple.

## Downloads

| File | Choose this for |
| --- | --- |
| `MacPowerScheduler-macos-universal-0.1.0.zip` | Intel or Apple Silicon Macs |
| `MacPowerScheduler-macos-arm64-0.1.0.zip` | Apple Silicon Macs only; smaller download |
| `*.dSYM.zip` | Crash investigation; not needed to use the app |
| `SHA256SUMS` | Verify downloaded ZIP checksums |

Both app variants contain the matching privileged helper and `powerschedulectl`. Move the extracted app into Applications and follow the README's setup instructions. Do not install both variants side by side.

## Included

- Independent daily startup and shutdown controls with a clear saved-versus-unsaved display.
- Contextual scheduling setup, a Settings sheet, and explicit replacement/removal confirmations.
- CLI JSON output, stale-state conflict detection, and revocable automation access.
- Preservation of one-time power events and unsaved editor changes after read failures.

## Validation and limits

The maintainer reports successful functional testing on an Intel Mac mini running macOS 15.7.4. Hosted automated tests also pass on Intel macOS 15.7.9. Apple Silicon execution has not been verified on hardware. Detailed signed-peer/account/lifecycle receipts and attended VoiceOver/Escape evidence are not yet complete.

Both ZIPs passed architecture, signature, stapled-ticket and Gatekeeper checks after extraction. Their debug symbols match all three bundled executables. The notarized Universal CLI passed read-only status/error/help checks on Intel.

Scheduled shutdown can be blocked by unsaved work or an unsuitable login/sleep state. Power-on depends on hardware and connected power; FileVault may require someone to unlock the Mac. The app does not force shutdown or change FileVault/login settings. Removing the helper leaves scheduled events in place unless they are explicitly cleared first.
